# Machine-Local OpenCode Preferences

Copy this file to `opencode.local.instructions.md` in the same directory and keep the copy gitignored.

Record only durable personal or machine-local preferences here, for example:

- Preferred chat language and communication style.
- Local availability or manual-action coordination constraints.
- Authenticated model inventory and machine-specific routing preferences.

Do not store credentials, tokens, passwords, task-specific notes, private prompts, or project policy in this file.
