## ADDED Requirements

### Requirement: Required leaves precede client integration

The disposable fixture SHALL prove schema and transport leaves before the distinct client integration oracle and SHALL preserve passing evidence when a hidden prerequisite affects only one leaf.

#### Scenario: Hidden schema prerequisite is isolated

- **WHEN** schema execution exposes an independently testable input prerequisite
- **THEN** only the affected leaf and parent gain that dependency
- **AND** passing transport evidence, accepted scope, and proposal remain unchanged.
