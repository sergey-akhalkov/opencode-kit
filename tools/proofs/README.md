## Operating Rules

- `session-completion-guard-restart.ts --scenario claims` reuses the runner's isolated installed server, local effect-free provider, immutable evidence, and cleanup boundary for representative-overclaim continuation, supported exact stop, truncated closure, and unchanged Ordinary Small idle behavior. It makes zero external provider calls and is not the matched configured-model proof owned by the consumer-outcome harness.
- Run `preflight` before `live` and preserve its JSON route evidence.
- `deduplication-audit.ts` uses direct `opencode run` because the accepted boundary is fresh primary slash-command loading; the shared SDK session helper does not expand that command path.
- Its provider-free `sanitize` mode rewrites only path strings in preserved JSON bundles: `node tools/proofs/deduplication-audit.ts --mode sanitize --evidence-root <path>`.
- Its provider-free `scenario-preflight` mode runs the installed CLI against selected synthetic workspaces before model capture: `node tools/proofs/deduplication-audit.ts --mode scenario-preflight --evidence-root <path> --scenarios id,...`.
- Its `evaluate` mode accepts `--baseline-override-root` and `--candidate-override-root` to compose corrected scenario-only captures without overwriting preserved earlier bundles.
- A live-attempt gate, provider authorization, and evidence/cleanup plan remain mandatory; this inventory does not grant authority.
- Before any configured-provider OpenSpec command proof, provider-free preflight the disposable root for the candidate command/skill source, complete `openspec/config.yaml`, the project-native operation-gate adapter and exact argv, a writable contained root when authoring is required, and an evidence/cleanup plan. Stop before inference when any item is absent; command loading alone does not prove the complete project authoring contract.
- Output is privacy-safe and structural. Raw provider text and completion evidence are not printed.
- For evidence-heavy changes, resolve one named lane with `node tools/evidence-index.ts --index <change-root>/evidence-index.json --lane <lane-name>` before reading raw bundles. The bounded resolver checks only selected-lane file references and never emits retry or bundle content.
- Add every new proof runner or shared proof library to this table with its boundary, modes, effects, cleanup, and exact invocation.
