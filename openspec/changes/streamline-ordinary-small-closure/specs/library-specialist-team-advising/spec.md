## MODIFIED Requirements

### Requirement: Non-trivial root tasks receive proportional team advice

After initial foraging has established the original goal reference, observed repository/task state, material unknowns, current candidate or worktree identity, and operating constraints without creating a decision-material plan or behavior-affecting mutation, main SHALL obtain one fresh bounded team recommendation only when current evidence identifies a concrete team-selection uncertainty: multiple plausible expertise surfaces, an exact unavailable capability, unique independent evidence, a useful but unresolved isolation/delegation boundary, or a non-local integration shape whose package choice can change the next accepted action. A root mission episode begins when a parentless user-facing root session accepts a new outcome that is not a continuation of its current accepted mission. Child specialists, guard/compaction sessions, campaign executor sessions, and propose/apply commands continuing the same outcome SHALL NOT begin another episode.

A task SHALL remain direct when main has sufficient current context to own the accepted result and no concrete team-selection uncertainty exists. Direct eligibility SHALL NOT depend on the task being trivial, one-file, or one-action. Registered Practice Owner triggers remain independent and SHALL NOT require advisor discovery. The advisory pass SHALL NOT create a fixed lifecycle phase or require a specialist merely because one is available. Once advice is actually obtained, it SHALL remain valid for the advisor to return `main-alone` when no skill or subagent adds unique task-relevant value.

#### Scenario: Trivial owner-local work stays direct

- **WHEN** current evidence shows one cohesive accepted owner and proof path with no competing expertise surface, unavailable required capability, unique independent-evidence need, unresolved isolation value, non-local integration package choice, or material uncertainty
- **THEN** main proceeds without team advice even when the work is non-trivial
- **AND** the ordinary outcome, safety, worktree, proof, and validation floor remains unchanged.

#### Scenario: New non-trivial root task receives one advisory pass

- **WHEN** a new root task has multiple plausible expertise surfaces, a material unknown tied to capability selection, a useful unresolved delegation boundary, or a non-local integration shape
- **THEN** main obtains one fresh bounded team recommendation after initial foraging and before the package-dependent execution or behavior-affecting mutation
- **AND** no fixed reviewer sequence or all-agent checklist is created.

#### Scenario: Same mission moves from propose to apply

- **WHEN** a parentless root session continues the same accepted mission from OpenSpec proposal into apply without a material topology change
- **THEN** that command transition does not begin a second advisory episode
- **AND** current engagement state remains subject only to its existing reconsultation condition.

#### Scenario: Campaign executor is a child control plane

- **WHEN** a campaign controller creates a child executor for work already decomposed under another mission control plane
- **THEN** the child does not treat its startup as a new user root advisory episode
- **AND** any future campaign integration remains separately specified rather than inferred by this capability.

#### Scenario: Advisor recommends main-alone

- **WHEN** a concrete team-selection uncertainty activated the advisor but the active catalog shows no skill or subagent adds unique evidence or bounded execution value
- **THEN** it returns `main-alone` with the exact evidence and reconsultation condition
- **AND** main continues without dispatching a ceremonial specialist.

#### Scenario: Catalog failure is scoped to the required choice

- **WHEN** the catalog is unavailable and one accepted item depends on a catalog-backed package choice while another accepted item has a direct sufficient route
- **THEN** only the package-dependent item remains unknown or blocked
- **AND** main continues the independent direct item without a mission-wide Team Advice state.
